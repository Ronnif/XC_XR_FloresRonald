## Descripción del Proyecto
Proyecto de realidad extendida desarrollado en Unity con XR Interaction Toolkit. Representa una sala de entrenamiento XR con objetos manipulables, interacción a distancia mediante rayo y sistema de teletransporte.

## Funcionalidades Implementadas
- **Escenario XR:** Piso, iluminación, límites visuales (4 paredes) y 5 objetos 3D
- **Objetos manipulables:** 2 objetos con Rigidbody y XR Grab Interactable (cubo rojo y esfera azul)
- **Interacción a distancia:** Cambio de color del cubo morado mediante rayo (XR Ray Interactor)
- **Teletransporte:** Área de teletransporte para moverse por la escena

## Controles e Instrucciones
- **Agarre de objetos:** Presiona el gatillo del controlador sobre un objeto manipulable
- **Interacción a distancia:** Apunta con el rayo al cubo morado y presiona el gatillo para cambiar su color
- **Teletransporte:** Apunta con el rayo al área de teletransporte y presiona el gatillo

## Tecnologías y Paquetes Utilizados
- Unity 6000.3.10f1
- Universal Render Pipeline (URP)
- XR Interaction Toolkit
- OpenXR
- Input System
